# Dabia UI Design System & Specifications

## 1. Core Design Language
- Theme concept: Warm Minimalist and Intellectual
- Accent direction: Terracotta / Burnt Orange
- Deprecated theme: Sora-iro is deprecated and should not be reintroduced

## 2. Color Palette
- Canvas: `#F9F9F8`
- Surface: `#FFFFFF`
- Overlay: `#F2F0EF`
- Primary Text: `#2A2A29`
- Secondary Text: `#888888`
- Border: `#E6E6E3`
- Brand Primary: `#D97757`
- Brand Light: `#F2DCD6`
- Brand Dark: `#B05030`

## 3. Typography
- Headings: `Noto Serif JP`
- Body: `Inter`

## 4. Grammar Skeleton UI Direction
- Grammar is a supporting layer, not the dominant card content.
- The base flashcard flow should remain lightweight.
- Preferred presentation for the current phase:
  - collapsible or secondary panel attached to the card
  - compact list of grammar points with short explanations
  - avoid full parser trees or dense linguistic notation

## 5. Interaction Constraints
- Grammar details should be available on demand.
- Review flow speed must not regress because of grammar UI.
- Mobile layout must keep the core answer area readable before any grammar expansion.
