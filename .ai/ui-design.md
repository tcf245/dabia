# Dabia UI Design Context

## 1. Current Visual Direction
- Warm editorial style with Terracotta accents
- Minimal surfaces and calm spacing
- Japanese content should feel intentional and readable

## 2. Grammar Skeleton UI Direction
- Grammar is a supporting layer, not the dominant card content.
- The base flashcard flow should remain lightweight.
- Preferred presentation for Phase 1:
  - collapsible or secondary panel attached to the card
  - compact list of grammar points with short explanations
  - optional sentence structure row for subject/topic/object/predicate style hints
- Avoid overwhelming the learner with full parser trees or dense linguistic notation.

## 3. Interaction Constraints
- Grammar details should be available on demand.
- Review flow speed must not regress because of grammar UI.
- Mobile layout must keep the core answer area readable before any grammar expansion.
