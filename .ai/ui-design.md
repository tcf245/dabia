# Dabia UI Design System & Specifications

## 1. Core Design Language
- **Reference**: `docs/dev_logs/2025-12-20_UI_Specification_Update.md`
- **Theme Concept**: "Warm Minimalist" & "Intellectual". 
- **Accents**: Terracotta / Burnt Orange.
- **Deprecated Themes**: "Sora-iro" (Sky Blue) theme is **DEPRECATED**. Do not use sora colors in the project. Any existing references to sora should be ignored or removed.

## 2. Color Palette

### Base Layer
- **Canvas / App Background**: `#F9F9F8` (Warm off-white)
- **Surface / Card Background**: `#FFFFFF` (Pure white)
- **Overlay**: `#F2F0EF` (Light warm gray)

### Content Layer
- **Primary Text**: `#2A2A29` (Soft Charcoal)
- **Secondary Text**: `#888888` (Warm Gray)
- **Border**: `#E6E6E3` (Subtle Warm Gray)

### Brand Layer (Terracotta Accents)
- **Brand Primary**: `#D97757` (Terracotta/Burnt Orange)
- **Brand Light**: `#F2DCD6` (Pale Apricot)
- **Brand Dark**: `#B05030` (Deep Earth)

## 3. Typography
- **Headings**: `Noto Serif JP`
- **Body**: `Inter`
