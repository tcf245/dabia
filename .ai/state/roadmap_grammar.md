# Atomic Grammar Roadmap: "Grammar as Intuition"

## Core Philosophy
Shift from "textbook" grammar modules to "atomic" interactions where grammar is a property of words and the skeleton of sentences.

## 1. Dynamic Particle Tiles
- Pain point: users know words and verbs but struggle with the particle in between.
- Interaction idea: expose particle slots and let the user test alternatives.

## 2. Conjugation Dial
- Pain point: conjugation tables feel overwhelming.
- Interaction idea: let users pivot by time, politeness, and polarity with immediate sentence feedback.

## 3. Grammar Skeleton
- Pain point: example sentences look like a wall of text.
- Interaction idea: show sentence structure as a lightweight annotated layer over the existing card.

## 4. Playground
- Phrase Lab
- Conjugation Lab
- Scenario Switcher

## 5. Implementation Notes
- Current shipped feature is only the first supporting layer for this roadmap.
- Phase 1 is display-only and built on top of existing cards.
