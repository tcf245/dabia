# SRS v3 Algorithm Implementation

**Date**: 2025-12-21
**Author**: Antigravity (Assistant)
**Status**: Implemented

## 1. Overview
We overhauled the Spaced Repetition System (SRS) to a ** Proficiency State Machine** (Levels 1-5).
Previous versions used a purely mathematical stability model (FSRS-like) which was hard to tune for specific user "feeling".
v3 implements explicit transitions requested by the product team.

## 2. Proficiency Definitions
| Level | Name | Interval Strategy |
| :--- | :--- | :--- |
| **L1** (New) | 没见过的新单词 | Immediate (0s) -> L2 or L5 |
| **L2** (Hard) | 这个单词需要多练练 | Short Queue (+90s) |
| **L3** (Learning)| 就要学起来了 | Medium Queue (+5m) |
| **L4** (Easy) | 唾手可得 | Long Term (+1 Week) |
| **L5** (Mastered)| 记忆满点 | Long Term (+1 Month) |

## 3. Implementation Details

### Core Logic
Located in `backend/dabia/core/scheduler.py`:
- **State Machine**: Replaced `_calculate_proficiency` with explicit IF/ELIF blocks handling L1-L5 transitions.
- **Intervals**: Defined in `srs_constants.py` to allow easy tuning without touching logic.

### Constants
`backend/dabia/core/srs_constants.py`:
- `INTERVAL_L2_SECONDS = 90`
- `INTERVAL_L3_SECONDS = 300`
- `INTERVAL_L4_DAYS = 7`
- `INTERVAL_L5_DAYS = 30`

## 4. Verification
### Unit Tests
New test suite `tests/unit/test_scheduler_v3.py` covers:
- L1 -> Correct -> Graduate (L5)
- L1 -> Incorrect -> L2
- L2 -> L3 -> L4 -> L5 Progression
- Regressions (Incorrect at L4/L5 -> L3)

Run tests with:
```bash
uv run pytest backend/tests/unit/test_scheduler_v3.py
```
